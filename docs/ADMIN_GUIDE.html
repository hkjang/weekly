Weekly 엔터프라이즈 관리자 가이드 (Admin Guide)

문서 버전: v0.3.0-ENTERPRISE
작성일자: 2026년 8월 9일
대상: 시스템 관리자, Security/DevOps
분류: 공식 관리자 & 운영 매뉴얼

1. 시스템 부트스트랩

WEEKLY_POSTGRES_DSN=postgres://weekly:Secr3tPass@10.10.30.5:5432/weekly?sslmode=disable
WEEKLY_BOOTSTRAP_ADMIN=admin
WEEKLY_BOOTSTRAP_ADMIN_PASSWORD=SuperSecretAdminPassword123!

2. Keycloak OIDC SSO 및 RBAC 연동

역할 (Role) 개인 작성 팀 승인/반려 조직 전체 조회 PPTX 템플릿 등록 OIDC/시스템 설정 감사 로그
ADMIN ✅ ✅ ✅ ✅ ✅ ✅
ORG_MANAGER ✅ ✅ ✅ ❌ ❌ ❌
TEAM_LEADER ✅ ✅ ❌ (소속 팀만) ❌ ❌ ❌
USER ✅ ❌ ❌ (본인 것만) ❌ ❌ ❌

3. 사내 PPTX 템플릿 등록 및 토큰 검증

관리자 화면에서 사내 표준 PPTX 파일을 업로드하면 원본 디자인 양식을 보존하면서 {{THIS_WEEK}}, {{NEXT_WEEK}}, {{ISSUES}} 토큰이 자동 교체됩니다.

4. AI Gateway 및 과거 PPTX Import

관리자 설정 → AI · Import에서 OpenAI 호환 Chat Completions 전체 Endpoint, 모델, 선택형 API Key와 호출·업로드 제한을 관리합니다. API Key는 인스턴스 키로 암호화되며 환경변수는 추가되지 않습니다.

설정 저장 후 AI Structured Output 연결 시험을 실행하고 AI 기능을 켭니다. PPTX 원본 보존기간이 지나면 바이너리만 제거되고 파일 해시, 추출 결과, 확정 보고 연결과 감사 기록은 PostgreSQL에 남습니다.
