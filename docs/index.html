Weekly는 외부 통신이 차단된 사내 폐쇄망 및 온프레미스 인프라에서 임직원의 주간보고 수집, 팀장 검토/승인 워크플로, Keycloak OIDC 계정 연동 및 사내 양식을 그대로 유지하는 PPTX 토큰 치환 내보내기를 완벽하게 제공하는 통합 솔루션입니다.

주요 기능

사내 주간업무 작성부터 최종 경영진 보고서 생성까지 한 번에 처리합니다

📝

체계적인 ReportItem 모델

금주 실적, 차주 계획, 주요 이슈, 진척도(% ) 데이터를 항목별로 세분화하여 체계적인 업무 기록과 빠른 검색을 보장합니다.

📊

PPTX 템플릿 보존 엔진

관리자가 등록한 PPTX의 마스터, 레이아웃, 도형, 글꼴을 100% 보존하면서 {{THIS_WEEK}}, {{NEXT_WEEK}} 토큰만 자동 치환하여 내보냅니다.

🔄

선택형 팀장 승인 워크플로

Draft ➔ Submitted ➔ Approved / Revision Requested 상태 전이 흐름을 지원하여 팀 단위 주간보고 검토 및 반려 절차를 효율화합니다.

🔐

Keycloak OIDC & RBAC

Keycloak OIDC SSO(PKCE) 지원 및 USER, TEAM_LEADER, ORG_MANAGER, ADMIN 4단계 조직 계층 RBAC 권한을 제공합니다.

🤖

Analytics MCP 연동

Streamable HTTP MCP 서버를 제공하여 Claude, Cursor 등의 AI 에이전트가 주차별 제출률 및 보고서를 자연어로 조회합니다.

📦

오프라인 단일 컨테이너

Go 백엔드와 React 정적 자산이 통합된 단일 non-root Docker 이미지로 인터넷 연결이 없는 에어갭 환경에 즉시 반입 가능합니다.

✨

검토 가능한 AI 초안

자유 텍스트를 구조화된 금주 실적·차주 계획·이슈로 변환하고 사용자가 수정·병합·교체한 뒤에만 저장합니다.

📥

과거 PPTX Import

Open XML 텍스트와 표를 안전하게 파싱하고 주차·신뢰도·중복을 확인한 뒤 과거 보고 데이터로 확정합니다.

승인 워크플로 & 모니터링

조직 규모에 맞춰 유연하게 설정 가능한 검토 및 제출 관리 프로세스

오프라인 설치 가이드

단일 Docker 이미지로 오프라인 폐쇄망 환경에 빠르게 배포하세요

🐳 Single Docker Archive Load

GitHub Release의 .tar.gz 패키지 하나만 오프라인망으로 반입하여 구동합니다.

gzip -dc weekly-v0.3.0-linux-amd64-docker.tar.gz | docker load
cp deploy/.env.example deploy/.env

# deploy/.env 환경변수 설정 후 실행
docker compose --env-file deploy/.env -f deploy/compose.yaml up -d

⚙️ 3대 필수 환경변수

프로세스가 요구하는 필수 환경변수는 단 3개입니다.

WEEKLY_POSTGRES_DSN=postgres://weekly:pass@localhost:5432/weekly
WEEKLY_BOOTSTRAP_ADMIN=admin
WEEKLY_BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!

자주 묻는 질문 (FAQ)

네. 프론트엔드 정적 파일과 백엔드 Go 바이너리가 단일 Docker 이미지로 내장되어 있어 인터넷 연결이 전혀 없는 폐쇄망에서도 100% 독립 동작합니다.

네. 관리자 화면에서 사내 표준 PPTX 파일을 등록하면 원본 슬라이드 마스터, 레이아웃, 표, 글꼴 및 이미지를 보존하면서 {{THIS_WEEK}}, {{NEXT_WEEK}} 토큰만 자동 교체합니다.

네. Weekly는 Streamable HTTP MCP 서버를 탑재하여 개인 API/MCP 키만 등록하면 AI가 자연어로 이번 주 제출 현황 및 보고서를 검색하고 답변할 수 있습니다.
