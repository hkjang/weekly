Air-Gapped Deployment Guide

Deploy quickly in offline environments using a single Docker image

🐳 Single Docker Archive Load

Import the single .tar.gz package from GitHub Release into your offline network.

gzip -dc weekly-v0.5.0.tar.gz | docker load
cp deploy/.env.example deploy/.env

# Configure environment variables in deploy/.env
docker compose --env-file deploy/.env -f deploy/compose.yaml up -d

⚙️ Required Settings and Stable Encryption Key

Set the three required values and retain one 32-byte encryption key across upgrades.

WEEKLY_POSTGRES_DSN=postgres://weekly:pass@localhost:5432/weekly
WEEKLY_BOOTSTRAP_ADMIN=admin
WEEKLY_BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!
WEEKLY_ENCRYPTION_KEY=<output of openssl rand -base64 32>
